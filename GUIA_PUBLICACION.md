# Publicación del portafolio / Publicação do portfólio

**Repositorio existente:** https://github.com/dante59/cv  
**Branch de publicación:** `main`

## Publicar una versión web con GitHub Pages

El repositorio contiene `index.html` preparado para un sitio estático, pero **publicarlo en GitHub no habilita Pages automáticamente**.

1. Entra en [Settings → Pages](https://github.com/dante59/cv/settings/pages).
2. En *Build and deployment*, selecciona **Deploy from a branch**.
3. Selecciona **main** y **/(root)** y guarda.
4. Una vez que GitHub confirme el despliegue, la dirección esperada será: **https://dante59.github.io/cv/**.

No difundas la URL de Pages hasta confirmar que carga correctamente.

## Antes de presentar el enlace a reclutadores

- Comprueba fechas de experiencia, especialmente el último período remoto en DroneHouse.
- Mantén separadas la **experiencia profesional**, las **propuestas académicas** y los **prototipos**.
- La cifra de 800+ clientes es autorreportada; utilízala únicamente si puedes explicarla en una entrevista.
- No publiques ingresos, facturación o utilidades sin conciliación y sin decidir que son datos aptos para difusión.
- No subas bases de clientes, contratos, datos personales de terceros, credenciales, código privado, presupuestos internos ni presentaciones grupales completas sin autorización.
- Antes de una postulación, adapta la versión [CV_ES.md](CV_ES.md) a la vacante.
